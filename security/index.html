Clear about what
happens to your data.

The tools are designed to work locally in your browser. This page explains the processing boundaries and their limits.

JWT processing

The JWT inspector decodes the visible header and payload locally with JavaScript. It does not call a JWT decoding API, and it does not verify a token signature, issuer, audience or authorization policy. The generated inspection view may contain sensitive claims, so avoid taking screenshots or sharing copied output with credentials intact.

CSS clamp calculation

The CSS clamp generator performs arithmetic in the browser. Values you enter are used to calculate and preview a CSS declaration; the page does not need a server to calculate the result.

What this site does not promise

Local processing is not a guarantee that the device, browser extensions, operating system, clipboard or surrounding environment is secure. Use a trusted device, keep software updated and avoid exposing production tokens in shared environments.

The tools are for inspection and development assistance. They do not replace application-level validation, security review, browser testing or accessibility evaluation.

Security questions

Send a sanitized description to ekanshprataps@gmail.com. Do not include passwords, live tokens, secrets or private keys.
